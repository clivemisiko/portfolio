03How I build AI

The report generator, stage by stage.

clive@report-tool

clive@report-tool:~$ cat pipeline.md

Checking first, writing second

In a report people make investment decisions on, a wrong figure is the failure that matters most. So the tool is built around verification. The model drafts, and nothing reaches an analyst until its numbers have been checked against the data they came from.

pipeline
Stage What happens
01 ingestThe week's data comes in from CBK, NSE and REIT sources.
02 draftAn LLM writes the report sections from that data.
03 verifyEvery figure in the draft is checked against its source value.
04 reviewAn analyst reads the draft alongside the checks in a review app, then signs off.
stack
backend
FastAPI service for drafting, checking and review state.
review app
Next.js front end where analysts read, check and approve.
runtime
Containerised with Docker Compose.
tests
700+ automated tests.
